V15.9 UNIVERSAL IMAGE SUPPORT
Every required website image now uses the same fallback system.

You can keep the exact BASENAME from this guide and use ANY ONE of:
.jpg
.jpeg
.png
.webp

Example:
stan-rittner-profile.jpg
stan-rittner-profile.jpeg
stan-rittner-profile.png
stan-rittner-profile.webp

All four will work automatically.

This applies to:
- Hero poster
- Home featured image
- All 16 UAG Universe images
- All 20 Brand Collaboration images
- Every Artist profile and gallery image
- Every Model profile and gallery image
- Priscilla and every Executive Team portrait
- Carol Ferrone
- All Event slider images
- All Press & Media images
- Unscripted with Priscilla

IMPORTANT:
Keep the folder and basename exactly the same. Only the file extension may change.

V15.10 IMAGE HOVER BEHAVIOUR
- All still images display in black and white by default.
- Hovering any image reveals the full-colour original.
- The hover transition is smooth and includes a subtle zoom.
- The homepage hero poster/video is intentionally excluded from this treatment.

V15.12 DISPLAY BEHAVIOUR
- Every real still image starts in black and white.
- Hovering the image reveals the original uploaded colour.
- The image wrapper itself is never grayscale, preventing older CSS rules from blocking the colour reveal.
- Card hover also reveals image colour where cards contain overlays or labels.
- Homepage category titles (Artists, Models, Events, Press & Media) are kept crisp and are never blurred or transformed.
- The moving homepage hero/poster remains exempt from the still-image hover treatment.

V15.13 FINAL HOVER RULE
- EVERY real still image loaded through the website media system is BLACK AND WHITE by default.
- On hover, CSS filter becomes NONE, revealing the exact original colour of the uploaded file.
- Moving the mouse away restores black and white.
- ARTIST in the P5 United / Artist / Group sequence has no blur at any point.

V15.17 FLEXIBLE GALLERIES
- Brand collaboration popups now show ONE image at a time with left/right arrows.
- Brand images share the same 4:3 display frame. Original proportions are preserved inside it.
- Add collaboration images sequentially: collab-samsung-01, -02, -03, -04, etc.
- Event galleries no longer assume exactly 6 images.
- Add event images sequentially: event-<event-key>-01, -02, -03, -04, etc.
- The website automatically discovers sequential images, up to 30 collaboration images and 40 event images.
- Supported extensions: jpg, jpeg, png, webp, and uppercase JPG/JPEG/PNG/WEBP.
- Keep numbering continuous. For example, do not have -01, -02, -04 without -03.
